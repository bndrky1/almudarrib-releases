# المدرّب: مدربك الصوتي لروكت ليق

هذا المستودع فيه **ملفات التثبيت والتحديثات بس**.

## التثبيت
1. افتح [آخر إصدار](https://github.com/bndrky1/almudarrib-releases/releases/latest) ونزّل الملف `AlMudarrib_Setup_….exe`.
2. شغّله. ممكن يطلع لك ويندوز رسالة زرقاء «Windows protected your PC» لأن البرنامج للحين غير موقّع: اضغط «More info» وبعدها «Run anyway».
3. يتثبّت لحسابك بس، وما يحتاج صلاحية مدير.

## التحديثات
البرنامج يشيّك هنا كل كم ساعة. لما ينزل إصدار جديد يطلع لك زر «حدّث الحين» في اللوحة وفي قائمة الأيقونة جنب الساعة، وبعدها يحدّث نفسه ويرجع لحاله.
كل تحديث موقّع رقمياً، والبرنامج يرفض أي ملف ما عليه توقيعنا.

## الخصوصية
البرنامج يشتغل على جهازك، وما يرسل بيانات لعبك لأي مكان، إلا لو ربطته أنت بمدربك (تقرير يوصل ديسكورد مدربك بعد كل جلسة).

برنامج مستقل، ما يتبع Psyonix ولا Epic Games.
